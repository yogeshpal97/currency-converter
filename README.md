# Currency Converter

A responsive currency conversion web application built with HTML, CSS, and JavaScript. The application integrates the Frankfurter API to fetch exchange rates and dynamically calculate currency conversions based on user input.

## Features

- Convert amounts between multiple currencies
- Fetch exchange rates through the Frankfurter API
- Dynamically populate currency selection options
- Automatically update currency flags
- Validate and handle user-entered amounts
- Display converted amounts dynamically
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Frankfurter API
- Font Awesome

## Core Concepts

- DOM Manipulation
- Event Handling
- Fetch API
- Async/Await
- JSON Data Handling
- API Integration
- Dynamic Element Creation
- JavaScript Template Literals

## Application Flow

1. User selects the source and target currencies.
2. User enters the amount to be converted.
3. JavaScript sends a request to the Frankfurter API.
4. The API returns the exchange rate in JSON format.
5. JavaScript calculates the converted amount.
6. The result is dynamically displayed in the interface.

## API

This project uses the Frankfurter API to retrieve currency exchange rates.
